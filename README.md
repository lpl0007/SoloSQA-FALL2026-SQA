## Project

This repository contains the KubeSec project used for the Fall 2026 Software Quality Assurance assignment.

The project applies software quality assurance activities to an existing Python project, including fuzz testing, forensic analysis, and continuous integration with GitHub Actions.

## Repository Structure

- `KubeSec-master/` - Original KubeSec Python project and its existing tests.
- `fuzz.py` - Automated fuzzing for selected Python methods. *(To be added.)*
- `SQA-REPO.md` - SQA activities, results, and lessons learned. *(To be added.)*
- `.github/workflows/` - GitHub Actions configuration for continuous integration. *(To be added.)*

## SQA Activities

The project will include:

1. Automated fuzzing of 10 Python methods.
2. Forensic analysis integrated into 10 Python methods.
3. GitHub Actions for continuous integration.
4. Documentation of bugs discovered, SQA activities, and lessons learned.
